Installing on Android Emulator

1. Download the MACRIC.apk file from the official GitHub Release link.
2. Drag and drop the downloaded APK into your BlueStacks, LDPlayer or MSI emulator window.
3. Open MACRIC and grant "Display over other apps" when prompted so the floating reticle HUD can draw on your game.
4. Select your game and launch HUD!
